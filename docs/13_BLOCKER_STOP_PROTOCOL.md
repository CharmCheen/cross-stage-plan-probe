# Blocker and Stop Protocol

## Luna must write BLOCKERS.md and stop the affected work when

- a spec ambiguity changes sample semantics, resource budget, plan definition, or metric boundary;
- the requested dataset/media is unavailable or incomplete enough to bias selection;
- a baseline cannot be implemented faithfully from the frozen mechanism definition;
- tracing cannot distinguish the claimed causal events;
- environment/hardware forces a semantic change;
- a requested action requires destructive changes, paid services, deployment, or external publishing.

## Early scientific stop signals

Luna does not make the final research judgment, but must flag:
- no input-side headroom;
- no binding memory in natural configs;
- H1 removes the gap;
- H2 dominates;
- only noncompetitive training schedules create crossing;
- H3/H4 reach REF within the stop range;
- effects occur only in artificial starvation/cold start.

Write `EARLY_STOP_EVIDENCE.md`, finish the minimum evidence required for audit, and stop before additional engineering.

## No moving goalposts

A negative result cannot trigger:
- new workload;
- new metric;
- new dimension;
- weaker baseline;
- different legality contract;
without explicit user-approved spec revision.
